# LuxAlgo

We're a trading technology company. We built [Vela](https://vela.luxalgo.com/chart), the next-generation charting platform: state-of-the-art charts for every market, with Quant, our coding agent, built in.

We started in the open. Since 2020 we've published free, open-source indicators on the charting platforms traders already used. When we built Vela, we built its foundations in the open too.

## Open source

- [Vela](https://github.com/LuxAlgo/Vela): the open-source core of Vela by LuxAlgo, a charting library for the web ([velacharts.dev](https://velacharts.dev))
- [PineTS](https://github.com/LuxAlgo/PineTS): our open-source Pine Script® runtime for JavaScript and TypeScript
- Free trading tools: [Trade Journal](https://github.com/LuxAlgo/trade-journal), [Edge Stats](https://github.com/LuxAlgo/edge-stats), [Prop Firm Sim](https://github.com/LuxAlgo/prop-firm-sim), [Market Trackers](https://github.com/LuxAlgo/market-trackers), [Broker SDK](https://github.com/LuxAlgo/broker-sdk), [Trade Relay](https://github.com/LuxAlgo/trade-relay), [Whale Options](https://github.com/LuxAlgo/whale-options)
